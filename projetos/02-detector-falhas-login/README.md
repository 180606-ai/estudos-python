# Detector de Falhas de Login

Projeto desenvolvido em Python para analisar um arquivo de logs
e identificar tentativas de login malsucedidas.

## Objetivo

Praticar Python e Linux através da análise de logs.

## Tecnologias

- Python
- Linux
- Termux

## Funcionamento

O programa:

1. Abre o arquivo `servidor.log`
2. Analisa cada linha
3. Procura por `LOGIN_FAILED`
4. Conta as falhas
5. Exibe o total encontrado

## Resultado

O programa identificou 4 falhas de login.
